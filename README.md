# Альбакор — готовый сайт

Сайт включает:
- продающую главную по водолазным работам;
- блок и программы обучения;
- форму заявок с сохранением в админ-панель;
- регистрацию и авторизацию учеников;
- личный кабинет;
- разделение доступа к документам по программам обучения;
- административную панель;
- создание программ;
- загрузку учебных файлов до 10 МБ или добавление ссылок;
- назначение программ конкретным пользователям;
- обработку статусов заявок;
- адаптивную мобильную версию.

## Запуск

Нужен Node.js 18 или новее.

```bash
npm start
```

Открыть:

http://localhost:5001

## Демо-администратор

E-mail: `admin@albakor.local`
Пароль: `Albakor2026!`

Для реального сервера обязательно задайте свои данные до первого запуска:

```bash
ADMIN_EMAIL=admin@example.ru ADMIN_PASSWORD='сложный-пароль' npm start
```

Если `data/db.json` уже создан, изменение переменных не изменит существующего администратора — удалите тестовую базу перед первым рабочим запуском или отредактируйте пользователя отдельно.

## Данные

- `data/db.json` — пользователи, программы, материалы, заявки и сессии.
- `uploads/` — загруженные учебные файлы.

Для небольшой организации такая версия подходит как рабочий прототип. Для публичного коммерческого сервера рекомендуется перенести данные в PostgreSQL/MySQL, включить HTTPS, резервное копирование, CSRF-защиту, ограничение попыток входа и журналирование действий администратора.

## Что заменить перед публикацией

В `public/index.html`:
- реальные телефон, e-mail и адрес;
- фактический опыт/количество объектов;
- реальные услуги, кейсы и цены;
- юридические документы и реквизиты.

Визуал можно менять в `public/styles.css`.
# Запуск с PostgreSQL

Приложение использует PostgreSQL. По умолчанию подключается к `localhost:5432`, базе `vodolaz` пользователем `postgres` и паролем `postgres`. Если ваши данные отличаются, задайте переменные окружения из `.env.example` перед запуском `npm start`.

При первом успешном запуске таблицы и учётная запись администратора создаются автоматически. Администратор по умолчанию: `admin@albakor.local` / `Albakor2026!` (изменяются переменными `ADMIN_EMAIL` и `ADMIN_PASSWORD`).
